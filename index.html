01 / Internal AI tool↗

Hours →to minutes

AI-assisted endpoint telemetry.

Connected an enterprise AI assistant to a written investigation playbook and API access across multiple endpoint telemetry sources. Analysts can ask for context and get useful results in minutes.

Behind the outcome +

The friction: querying separate telemetry sources slowed investigations.

The work: connected enterprise AI to a written query playbook and APIs for three endpoint data sources, with more being added.

The result: I have seen investigations that took hours move to minutes for me and teammates. This is an observed outcome, not a formal benchmark.
