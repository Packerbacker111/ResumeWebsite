A hands-on web challenge

Who gets to decide?

This page asks a real server endpoint whether you may see the flag. The first answer is no. Your mission is to change the request the browser sends.

01 / Mission

Turn access denied into access granted.

Open your browser’s developer tools and inspect the cookies for this site. Find show-flag, change its value, then check again. The server reads that cookie on each request.

Tip: look under Application or Storage. The cookie belongs to the /api/cookie-challenge path.

02 / Server response

The gate

Checking the server…

This uses an actual HTTP request. Refreshing or pressing the button sends your current cookie to the server.

This isolated puzzle is inspired by an earlier cookie CTF I designed. It does not grant access to anything else on the site.
